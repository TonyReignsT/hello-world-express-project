# Overview

This project is a simple Hello World web application built using Node.js and Express.js. The application starts a local web server and displays a “Hello World” message in the browser when accessed through a local host address.

The purpose of creating this software is to strengthen my understanding of backend development fundamentals, project setup, and how web servers work using Express.js. This project also helped me practice using GitHub, Git, Visual Studio Code, and documenting software projects professionally.


# Development Environment

The software was developed using the following tools:

- Visual Studio Code
- Node.js
- Express.js
- Git
- GitHub

The programming language used in this project is JavaScript.
